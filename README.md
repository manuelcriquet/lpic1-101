### Estructura del repositorio

```text
lpic1-101/
├── README.md              # esta portada
├── errores.md             # preguntas falladas y por qué
├── clases/
│   ├── _plantilla/        # molde de cada clase
│   ├── C00-laboratorio/

├── proyectos/

│   └── integradores/

```

Cada carpeta de clase tiene tres archivos: `README.md` (resumen de 1 página), `ejercicios.md` y `preguntas.md`.
